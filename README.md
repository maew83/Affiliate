# Affiliate Content Studio

เว็บแอปสร้างคอนเทนต์ affiliate สำหรับ Facebook Reels และ TikTok
ใส่ข้อมูลสินค้าและรูปสินค้า แล้วระบบจะทำให้ทั้งหมดนี้:

1. **แคปชันและสคริปต์เสียงพากย์**: เขียนโดย Claude ซึ่งดูรูปสินค้าและข้อมูลที่กรอกไว้
2. **เสียงพากย์ภาษาไทย**: สร้างด้วย Edge TTS (ฟรี)
3. **วิดีโอแนวตั้ง 9:16**: ทำเป็นสไลด์รูปสินค้า มี hook ช่วงต้นคลิปและซับที่ตรงกับเสียงพากย์

> เวอร์ชันนี้ทำแค่ส่วน **สร้างคอนเทนต์** ดาวน์โหลดวิดีโอและคัดลอกแคปชันไปโพสต์เองได้เลย
> ยังไม่มีระบบโพสต์อัตโนมัติและตั้งเวลาโพสต์

## สิ่งที่ต้องมี

- Python 3.10 ขึ้นไป
- ffmpeg ที่มี libass (ใช้ทำซับ)
  - Windows: `winget install ffmpeg`
  - macOS: `brew install ffmpeg`
  - Ubuntu: `sudo apt install ffmpeg`
- Claude API key จาก https://console.anthropic.com (ไม่ใส่ก็ได้ ดูหัวข้อ "ใช้แบบไม่มี API key")
- ฟอนต์ที่รองรับภาษาไทย เช่น Tahoma (มีใน Windows อยู่แล้ว) ตั้งชื่อฟอนต์ได้ที่ `SUBTITLE_FONT` ในไฟล์ `.env`

## ติดตั้งและรัน

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate    macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env      # แล้วใส่ ANTHROPIC_API_KEY
uvicorn app.main:app --reload
```

จากนั้นเปิด http://127.0.0.1:8000

## วิธีใช้

1. เพิ่มสินค้า: เลือกแพลตฟอร์ม (Shopee หรือ TikTok Shop) กรอกชื่อ ราคา จุดเด่น และลิงก์ affiliate แล้วอัปโหลดรูป
2. กด **ให้ AI สร้างคอนเทนต์** แล้วรอประมาณ 30-60 วินาที
3. ตรวจผลลัพธ์ ถ้าอยากแก้แคปชันหรือสคริปต์ ให้แก้ในช่องแล้วกด **บันทึกที่แก้ + ทำวิดีโอใหม่** (ขั้นตอนนี้ไม่เรียก AI ซ้ำ)
4. ดาวน์โหลดวิดีโอ คัดลอกแคปชัน แล้วนำไปโพสต์

## ใช้แบบไม่มี API key

ถ้าไม่ได้ใส่ `ANTHROPIC_API_KEY` ในไฟล์ `.env` (หรือยังเป็นค่าตัวอย่าง `sk-ant-...`) ปุ่ม AI จะถูกซ่อน
ให้พิมพ์ hook สคริปต์เสียงพากย์ และแคปชันเองในช่องใต้สินค้า แล้วกด **บันทึก + ทำเสียงและวิดีโอ**
ระบบจะทำเสียงพากย์และวิดีโอให้เหมือนเดิม โดยอย่างน้อยต้องใส่สคริปต์เสียงพากย์
ใส่ key ภายหลังได้ แล้วรีสตาร์ทโปรแกรม ปุ่ม AI จะกลับมา

## โครงสร้างโค้ด

| ไฟล์ | หน้าที่ |
|---|---|
| `app/main.py` | เว็บเซิร์ฟเวอร์และ API |
| `app/ai.py` | เรียก Claude ให้เขียนแคปชันและสคริปต์ |
| `app/tts.py` | สร้างเสียงพากย์และไฟล์ซับด้วย Edge TTS |
| `app/video.py` | ประกอบวิดีโอด้วย ffmpeg |
| `app/db.py` | เก็บข้อมูลใน SQLite (`data/affiliate.db`) |
| `app/static/index.html` | หน้าเว็บ |

## ข้อควรรู้

- AI ถูกตั้งไว้ให้ใช้เฉพาะข้อมูลที่กรอกและสิ่งที่เห็นในรูป และให้ระบุในแคปชันว่าเป็นลิงก์ affiliate
- Edge TTS ไม่ใช่ API ทางการของ Microsoft อาจใช้ไม่ได้ชั่วคราวหรือถูกเปลี่ยนในอนาคต
- ค่าใช้จ่าย Claude API คิดตามจำนวนครั้งที่กดสร้างคอนเทนต์
